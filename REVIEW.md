# Code Review Guidelines

## General Principles

- **Microsoft Best Practices**: All projects must follow Microsoft engineering best practices for code quality, maintainability, and operational excellence.
- **AI-Native Design**: Architecture and implementation should be AI-first, leveraging AI capabilities natively rather than as an afterthought.
- **Secure-by-Default**: Security is not optional. Every component must be designed with security as a foundational requirement, with secure defaults and defense-in-depth.
